Web Request Diagram

Request flow for GitHub
flowchart LR
    A[Browser] -->|1. Open URL| B[DNS Resolver]
    B -->|2. Find IP| C[ISP / Resolver]
    C -->|3. Return IP| D[Internet Routing]
    D -->|4. Send HTTPS Request| E[CDN / Edge Network]
    E -->|5. Forward Request| F[GitHub Web Server]
    F -->|6. Ask Backend| G[Application Server]
    G -->|7. Read Data| H[Database]
    H -->|8. Return Data| G
    G -->|9. Build Response| F
    F -->|10. Send HTML / JSON| E
    E -->|11. Deliver to Browser| A
